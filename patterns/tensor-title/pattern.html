Tensor Title Pattern

放在 matrix / volume / tiling 视图上方的共享标题条。身份、逻辑与物理 shape、dtype、format、内存、owner、partition、state、provenance、step、axes 和约束都由业务字段驱动。

Vector Add · GM → UB

逻辑 tensor、GM 线性地址、block / tile 切分和当前 CopyIn 步骤同时出现在标题条里。

placeholder canvas · 1D logical tensor

Matmul · L0C → GM

输出网格、base tile、K reduction、owner 和 provenance 组合成完整标题。

placeholder canvas · C[M,N] output grid

Compact · NCHW → NC1HWC0

紧凑密度保留主身份、角色和状态，隐藏 chips 与 footer。

字段组

标题条按主行、meta、chips、footer、status 五组渲染。业务只传结构化字段，不传 HTML。

primary · label / role / direction meta · shape / dtype / format / axes chips · memory / owner / partition / state footer · constraints / provenance status · step / live readout

Scene

required: label
字段说明
label主 tensor 名称或变量符号
role语义角色，例如 input / output / weight / bias / scratch / temp / reduction / fusion / broadcast / aggregate
logicalShape逻辑 shape，字符串或 { label, dims }
physicalShape物理布局 shape，例如 NC1HWC0、A1、A2
tileShape当前 tile 或 base tile shape
dtypedtype 或 dtype 链，例如 half → float → half
formatformat / layout 标识
axes坐标轴标签数组
memory{ tier, sizeBytes, offset, range, stride, alignment }
owner / queueDepth队列、分配器或 owning object
partition{ blockCount, blockLength, tileLength, blockIndex, tileIndex, tileRange }
state生命周期状态，例如 loading / loaded / enqueued / current / produced / free
direction数据搬运方向，例如 GM → UB
provenance{ symbol, file, line, evidence }
step{ phase, operationChips, stepIndex, totalSteps }
constraints约束数组，例如 32B aligned、no tail、padding、broadcast
status右侧实时状态文字

Options / Controller

render → controller
字段说明
ariaLabel无障碍标题，默认使用 label
densityfull 或 compact，compact 隐藏 chips / footer
showRole是否显示 role badge
showShapes是否显示 shape 组
showChips是否显示 chips 组
showStatus是否显示右侧 status
update()更新 scene / options 并原地重绘
destroy()清空标题条并移除 pattern 状态
 
const controller = PtoTensorTitle.render(host, scene, options);
controller.update(nextScene, { density: 'compact' });
controller.destroy();

使用说明

消费页面直接加载共享 CSS / JS 并调用 renderer，不通过 iframe，也不要在业务页复制标题 DOM 或字段格式化逻辑。

最小接入

<link rel="stylesheet" href="patterns/tensor-title/pattern.css">
<script src="patterns/tensor-title/pattern.js"></script>

const controller = PtoTensorTitle.render(
  document.getElementById('tensorTitle'),
  {
    label: 'xLocal',
    role: 'input',
    logicalShape: { label: '1D logical', dims: [16384] },
    physicalShape: { label: 'GM linear', dims: [16384] },
    tileShape: { label: 'tile', dims: [128] },
    dtype: 'float32',
    format: 'ND',
    memory: { tier: 'GM', sizeBytes: 65536, offset: 0, alignment: 32 },
    owner: 'xGm',
    partition: { blockCount: 8, blockLength: 2048, tileLength: 128, blockIndex: 0, tileIndex: 1 },
    state: 'loading',
    direction: 'GM → UB',
    step: { phase: 'CopyIn', operationChips: ['DataCopy', 'EnQue'], stepIndex: 1, totalSteps: 16 },
    status: 'block 0 · tile 1/16',
  }
);

更新与生命周期

controller.update(nextScene);
controller.update(
  { ...scene, state: 'enqueued' },
  { density: 'compact', showChips: false }
});
controller.destroy();

update 会原地重绘，不保留旧节点；destroy 清空标题条并移除 pto-tensor-title class。

PtoTensorTitle.render(

标题条只负责身份和元数据；体素 / 矩阵渲染仍由 tensor-volume-canvas 或 matrix-canvas 负责。

限制

  • 不要在业务页重写标题 DOM、字节格式或字段归一化逻辑。
  • 不要给标题条再套卡片、边框或页头装饰。
  • shape、format、memory、state 和 tiling 事实由业务传入，Pattern 不做推导。
  • 不要通过 iframe 使用；直接加载 pattern.css 和 pattern.js。
  • 文本统一以 textContent 插入，不接受业务 HTML 字符串。
